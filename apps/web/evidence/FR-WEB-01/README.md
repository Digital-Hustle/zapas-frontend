# FR-WEB-01 — лендинг

Лендинг дополнен графиком смоделированного прогноза, FAQ и пояснением о проверке точности.
График доступен без API. P50, интервал P10–P90, нулевой остаток и пользовательский порог
показаны отдельно. Исходные суммы остаются строками; пропуски не заменяются нулями.

## Проверки

- `node tools/check.mjs frontend contracts tooling security`: пройдено.
- Vitest: 12 тестов пакетов; repo tooling: 3 теста.
- `PLAYWRIGHT_CHANNEL=chrome pnpm --filter @zapas/web e2e`: 7 проверок пройдено.
- 360/768/1440 px, светлая/тёмная темы, reduced motion, клавиатурный переход к примеру,
  переход ко входу, отсутствие запросов к API и горизонтального переполнения.
- Axe: 0 нарушений serious/critical во всех шести сочетаниях ширины и темы.
- Gitleaks локально отсутствует; его проверяет обязательный GitHub workflow security.
