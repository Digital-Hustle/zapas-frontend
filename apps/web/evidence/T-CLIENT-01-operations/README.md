- VIEWER/архив/утрата роли отключают запись. Ошибка доступа скрывает кэш;
  outage сохраняет известные факты с пояснением и запрещает изменение категорий.
  Серверный detail не выводится пользователю. Изменение категорий инвалидирует
  financial scope для связанных данных, без оптимистического пересчёта денег.
