# Риск и качество — F1

Представления получают подготовленные доменные данные, без HTTP/DTO.
Риск — сценарная вероятность с availability; качество — отдельные nullable
метрики и counts. Компоненты не считают дефицит или сводный процент точности.

Реальные API, mapper и query hooks подключаются после handoff F2.
Для проверки отображений используется только dev-витрина с явной подписью
«Смоделированный пример»; production кабинет не получает fixtures.
