# Наблюдение за расчётом — T-CLIENT-01

F1 управляет отображением и polling публичного job. Loader внедряется из API
адаптера после F2 handoff; собственных fetch/base URL/CSRF здесь нет.

Интервал 1/2/5 секунд для QUEUED/RUNNING; terminal прекращает polling.
Смена company/job меняет query key; уход с экрана отменяет запрос через signal.
Запуск/повтор — отдельное действие, старый результат сохраняется.
