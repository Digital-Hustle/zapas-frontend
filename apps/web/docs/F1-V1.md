## Общий слой F2 готов к подключению

- API v1 смёржен в [#13](https://github.com/Digital-Hustle/zapas-frontend/pull/13):
  hub `abe85d7`, раздельные auth-profile/orchestrator/preprocessor и legacy auth,
  memory CSRF bootstrap, single-flight refresh без auto retry неопределённого результата.
  Подключение и ограничения — `docs/F2-API-V1.md` от корня frontend.
- FileDrop, EmptyState/ErrorState, Badge/RiskBadge, Stepper/Progress, Amount и Textarea
  смёржены в [#14](https://github.com/Digital-Hustle/zapas-frontend/pull/14).
- Остальные примитивы DESIGN §5 поставляются этим PR общего UI-кита: поиск и
  MultiSelect, DateRangePicker, меню/Popover/Tooltip, Sheet/AlertDialog, CommandPalette,
  ScrollArea, Table/VirtualTable. API и примеры — `packages/ui/README.md`.
- F1 подключает свои доменные порты/mapper к generated SDK. Старые login-by-code и
  entities/session ещё используют legacy http; это не новый Auth/Profile flow.
  Auth/Profile UI в draft [#12](https://github.com/Digital-Hustle/zapas-frontend/pull/12)
  пока не завершён. Gateway/Auth runtime и реальный upload отсутствуют на preview.

F1 не меняет shared API/UI/config, не создаёт обходной HTTP-клиент и не выдаёт
fixtures за backend. Независимые отображения принимают подготовленные доменные
данные; подключение к реальному API проверяется отдельным этапом.

Статус review означает готовый PR с проверками; done — только независимое ревью
и merge человеком. Word-копии удалены актуальным хабом и не восстанавливаются.
