## Конкретные зависимости F2

- `@zapas/api` экспортирует только старые auth/ledger/planning/forecast/notify.
  Нужны раздельные auth-profile/orchestrator/preprocessor namespaces и новый hub ref
  с удалением retired копий. Текущий ref — `7d6b86c`.
- `http.ts` читает legacy `zapas_csrf` и вызывает `/api/v1/auth/refresh`.
  Нужны memory CSRF bootstrap нового Auth/Profile, credentials include,
  single-flight refresh без сетевого auto retry; окончательный 401 отличается от outage.
- `FileDrop` отсутствует в публичном `@zapas/ui`. Скрытый file input вне него
  не добавляется. Table/EmptyState/ErrorState и прочие отсутствующие общие примитивы
  остаются F2; компоненты графика используют собственную семантическую таблицу данных.

F1 не меняет shared API/UI/config, не создаёт обходной HTTP-клиент и не выдаёт
fixtures за backend. Независимые отображения принимают подготовленные доменные
данные; подключение к реальному API проверяется отдельным этапом.

Статус review означает готовый PR с проверками; done — только независимое ревью
и merge человеком. Word-копии удалены актуальным хабом и не восстанавливаются.
