# Charts — зона F1

`@zapas/charts` экспортирует `ForecastChart` и типы `ForecastChartProps`, `ForecastPoint`.
Компонент принимает даты, готовые строки P10/P50/P90 и строку минимального остатка.
`null` означает пропуск; неполный интервал не рисуется. Исходные строки сохраняются;
`number` используется только для координат. Нулевой остаток и пользовательский порог
показаны разными линиями. Данные доступны скринридеру в таблице.

Recharts 3.10.1 (MIT), цвета и движение — из общих токенов. Анимация раскрытия — Motion;
при reduced motion график сразу виден. Собственные анимации Recharts отключены.

FR-WEB-01 использует фиксированный смоделированный пример, без API и расчёта прогноза.
Диапазоны, зум, тултип и события кабинета — FR-UI-02. PlanFactChart, Sparkline и RiskHeatmap
появятся в соответствующих следующих задачах F1.
