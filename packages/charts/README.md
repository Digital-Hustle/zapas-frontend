# Charts — зона F1

`@zapas/charts` экспортирует `ForecastChart` и типы `ForecastChartProps`, `ForecastPoint`.
Компонент принимает даты, готовые строки основного прогноза `balance`, P10/P50/P90,
`asOfDate`, отдельные фактические остатки `actuals` и nullable строку минимального остатка.
Основной прогноз и медиана сценариев P50 — разные линии. Факт ограничен asOfDate,
прогноз начинается после неё; между рядами нет соединения или интерполяции.
`null` означает пропуск; неполный интервал не рисуется. Исходные строки сохраняются;
`number` используется только для координат. Нулевой остаток и пользовательский порог
показаны разными линиями. Тултип и доступная с клавиатуры раскрываемая таблица
показывают исходные денежные строки без потери копеек даже за пределами safe integer.

Recharts 3.10.1 (MIT), цвета и движение — из общих токенов. Анимация раскрытия — Motion;
при reduced motion график сразу виден. Собственные анимации Recharts отключены.

Лендинг использует фиксированный смоделированный пример на 30 дней по hub v1,
без API и расчёта прогноза. Сценарный редактор, 90 дней и прежний backlog FR-UI-02
не являются требованиями v1. Загрузка данных и миграция общего API остаются отдельным этапом.
